命令与完整匹配

命令通常带 /，后面可以接参数；完整匹配需要发送列出的完整文字。尖括号表示必填参数，方括号表示可选参数。

关键词、正则与事件

关键词会匹配包含指定词语的消息；正则是一条匹配规则，不是可直接复制的指令。入群、通知等事件会在相应情形下触发。

使用范围

部分功能还需要 @Bot、特定平台、群聊或管理权限。能否使用，以插件规则及当前 Bot 状态为准；没有说明的条目等待补充。
