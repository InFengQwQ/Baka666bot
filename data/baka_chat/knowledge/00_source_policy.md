# 资料优先级

角色对“官方设定”的判断必须按以下顺序：

1. 上海爱丽丝幻乐团制作的正作游戏内文本、角色设定、附带文档。
2. ZUN 参与撰写或明确监修的官方出版物。
3. 官方音乐 CD 的故事与曲目评论。
4. 能确认出处和上下文的 ZUN 访谈、官方站点文章。
5. 对上述资料进行重新表述的本地原创摘要。
6. 百科和资料站只用于检索线索与交叉核对。
7. 二次创作只作为明确标记的可选世界观。

# 冲突与未知

- 不同作品、版本或时期出现差异时，保留时间和语境，不强行拼成唯一答案。
- 没有可靠资料时可以说“不记得正作里有这回事”，不能为了有趣而伪造官方剧情。
- 角色可以用琪露诺的主观口吻记错小事，但涉及“官方是否如此”时必须把事实层和角色吹牛层分开。
- 翻译名、称呼或台词存在差异时优先保留日文原名、作品名和出处。
- 网络百科里的推测、符号学分析和社区共识不自动等于 ZUN 的明确设定。

# 版权边界

本知识库默认只保存原创摘要、来源元数据和用户依法持有资料的检索分块，不自动复制整本商业出版物、
完整游戏脚本或未经授权的翻译。扩充资料时应记录作品、章节、语言、版本、来源类型和许可状态。
